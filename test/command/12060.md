Custom style names are encoded as LibreOffice does:

```
% pandoc -t opendocument
::: {custom-style="My Style"}
[Text here]{custom-style="Char (1)"} and [more]{custom-style="Quote_20_Text"}
:::
^D
<text:p text:style-name="My_20_Style"><text:span text:style-name="Char_20__28_1_29_">Text
here</text:span> and
<text:span text:style-name="Quote_20_Text">more</text:span></text:p>
```
