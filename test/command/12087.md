Nested relative includes are resolved relative to the including file.

```
% pandoc -f rst -t native
.. include:: command/12087/sub/a.rst
^D
[ Para
    [ Str "Nested"
    , Space
    , Str "RST"
    , Space
    , Str "paragraph."
    ]
]
```

```
% pandoc -f org -t native
#+INCLUDE: "command/12087/sub/a.org"
^D
[ Plain
    [ Str "Nested"
    , Space
    , Str "Org"
    , Space
    , Str "paragraph."
    ]
]
```
