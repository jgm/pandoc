Additional data directories given with `--data-dirs` are searched
in order, after the user data directory.

```
% pandoc -t plain --data-dirs=command/7922/a --data-dirs=command/7922/b --template=which.txt
hi
^D
a: hi
```

```
% pandoc -t plain --data-dirs=command/7922/b --data-dirs=command/7922/a --template=which.txt
hi
^D
b: hi
```

```
% pandoc -t plain --data-dir=command/7922/user --data-dirs=command/7922/a --template=which.txt
hi
^D
user: hi
```

```
% pandoc -t plain --data-dirs=command/7922/a --data-dirs=command/7922/b --template=only-b.txt
hi
^D
only b: hi
```

Metadata files are searched in the `metadata` subdirectory:

```
% pandoc -s -t native --data-dirs=command/7922/b --metadata-file=meta.yaml
hi
^D
Pandoc
  Meta
    { unMeta =
        fromList
          [ ( "title" , MetaInlines [ Str "From" , Space , Str "b" ] )
          ]
    }
  [ Para [ Str "hi" ] ]
```

Defaults files are searched in the `defaults` subdirectory:

```
% pandoc --data-dirs=command/7922/a --data-dirs=command/7922/b -d dd
hi
^D
only b: hi
```
