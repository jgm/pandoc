Footnote back-links need an accessible name: the bare arrow does not tell
a screen reader user where the link goes (#11965).

```
% pandoc -f markdown -t html5 --wrap=none
Text.[^1]

[^1]: Note.
^D
<p>Text.<a href="#fn1" class="footnote-ref" id="fnref1" role="doc-noteref"><sup>1</sup></a></p>
<section id="footnotes" class="footnotes footnotes-end-of-document" role="doc-endnotes">
<hr />
<ol>
<li id="fn1"><p>Note.<a href="#fnref1" class="footnote-back" role="doc-backlink" aria-label="Back to reference 1">↩︎</a></p></li>
</ol>
</section>
```

A language without a translation for the new term falls back to the
English label without emitting a warning (`--fail-if-warnings` guards
that):

```
% pandoc -f markdown -t html5 --wrap=none -M lang=de --fail-if-warnings
Text.[^1]

[^1]: Note.
^D
<p>Text.<a href="#fn1" class="footnote-ref" id="fnref1" role="doc-noteref"><sup>1</sup></a></p>
<section id="footnotes" class="footnotes footnotes-end-of-document" role="doc-endnotes">
<hr />
<ol>
<li id="fn1"><p>Note.<a href="#fnref1" class="footnote-back" role="doc-backlink" aria-label="Back to reference 1">↩︎</a></p></li>
</ol>
</section>
```

HTML4 output is unchanged: no role, no aria-label.

```
% pandoc -f markdown -t html4 --wrap=none
Text.[^1]

[^1]: Note.
^D
<p>Text.<a href="#fn1" class="footnote-ref" id="fnref1"><sup>1</sup></a></p>
<div class="footnotes footnotes-end-of-document">
<hr />
<ol>
<li id="fn1"><p>Note.<a href="#fnref1" class="footnote-back">↩︎</a></p></li>
</ol>
</div>
```
