A style based on itself:

```
% pandoc -f rtf -t native
{\rtf1{\stylesheet{\sbasedon0 Normal;}}\pard Hello\par}
^D
[ Para [ Str "Hello" ] ]
```

A cycle of two styles:

```
% pandoc -f rtf -t native
{\rtf1{\stylesheet{\s1\sbasedon2 A;}{\s2\sbasedon1 B;}}\s1 Hi\par}
^D
[ Para [ Str "Hi" ] ]
```

Formatting from the styles in a cycle is still applied:

```
% pandoc -f rtf -t native
{\rtf1{\stylesheet{\s1\sbasedon2\b A;}{\s2\sbasedon1\i B;}}\s1 Hi\par}
^D
[ Para [ Strong [ Emph [ Str "Hi" ] ] ] ]
```
