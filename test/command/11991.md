Notes and comments are read with the namespace prefixes declared in
their own parts (word/footnotes.xml, word/endnotes.xml,
word/comments.xml). Here word/document.xml declares only `w`; the
footnote's hyperlink uses `r`, and the equations in the endnote and
the comment use `m`.

```
% pandoc command/11991.docx -t native --track-changes=all
^D
[ Para
    [ Span
        ( ""
        , [ "comment-start" ]
        , [ ( "comment-id" , "0" )
          , ( "author" , "A" )
          , ( "date" , "2026-01-01T00:00:00Z" )
          ]
        )
        [ Str "Math:" , Space , Math InlineMath "x" ]
    , Str "Text"
    , Span
        ( "" , [ "comment-end" ] , [ ( "comment-id" , "0" ) ] ) []
    , Note
        [ Para
            [ Str "See"
            , Space
            , Link
                ( "" , [] , [] )
                [ Str "example" ]
                ( "https://example.com/" , "" )
            ]
        ]
    , Note
        [ Para [ Str "Math:" , Space , Math InlineMath "x" ] ]
    ]
]
```
