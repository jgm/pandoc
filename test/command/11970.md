Deprecated command-line options are reported with the other warnings, so
`--fail-if-warnings` and `--log` see them.

```
% pandoc --mathml --fail-if-warnings -t html
x
^D
2> [WARNING] Deprecated: --mathml. Use --math-method=mathml instead.
2> Failing because there were warnings.
=> 3
```

```
% pandoc --mathml --quiet -t html
x
^D
<p>x</p>
```
